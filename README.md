🎯 Online Quiz System

A simple full-stack quiz application built using HTML, CSS, Java, MySQL, and C.

---

🚀 Features

- 🔐 User Login System
- 📝 Attempt Quiz
- 📊 Store Questions in MySQL
- 📈 Result Analysis using C

---

🛠️ Tech Stack

- Frontend: HTML, CSS
- Backend: Java (Servlet)
- Database: MySQL
- Processing: C

---

📂 Project Structure

frontend/
backend/
database/
c_module/

---

⚙️ Setup Instructions

1. Import "quiz.sql" in MySQL
2. Configure DB username & password in Java file
3. Deploy project on Apache Tomcat
4. Open "login.html"
